# Assuria AI - Agent WhatsApp d'Assurance Maroc

Agent intelligent pour cabinet d'assurance au Maroc, propulsé par Gemini 1.5 Flash, Supabase et Node.js.

## Fonctionnalités
- **WhatsApp Webhook** : Intégration Meta Cloud API.
- **Gemini AI** : Moteur conversationnel spécialisé assurance Maroc.
- **Dashboard Advisor** : Interface React pour les conseillers.
- **Web Chat Widget** : Widget embeddable pour site web.
- **Supabase** : Base de données PostgreSQL pour conversations et demandes.

## Installation

### Backend
```bash
cd backend
npm install
npm start
```

### Dashboard
```bash
cd dashboard
npm install
npm run dev
```

## Déploiement
Configuré pour un déploiement direct sur **Railway**.
